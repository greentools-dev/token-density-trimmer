How It Works & Frequently Asked Questions

Why deterministic trimming instead of an LLM?

Prompting an LLM to rewrite your prompts consumes extra API tokens, takes several seconds of network latency, and frequently hallucinates by altering code variable names, subtle edge case conditions, or technical phrasing. A deterministic regex normalizer strips zero-value filler while leaving your core instructions 100% intact.

Are my sensitive prompts uploaded anywhere?

No. This tool operates 100% inside your browser using standard JavaScript string manipulation. No prompts, API keys, or proprietary data are ever sent over a network. It functions completely offline without internet connectivity.

What conversational filler gets removed?

LLMs do not require human pleasantries. The optimizer strips phrases such as "Please kindly", "Could you please", "Thank you in advance", "I would really appreciate it if you could", "As an AI model", "Here is what I need you to do:", and redundant conversational closings like "In conclusion".

How is the cost reduction calculated?

Calculations are based on benchmark input token pricing of standard frontier models ($2.50 per 1M input tokens for GPT-4o / Claude 3.5 Sonnet class). When running automated agent loops or high-frequency batch requests across 10,000 queries, eliminating 50 to 150 redundant tokens per request yields substantial monthly cost savings.
